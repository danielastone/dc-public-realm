# Object overview content rules

The overview answers four immediate reader questions: What is this? Where is it? When did it enter its Washington public history? What person or historical object does it concern?

Use the most specific sourced event label available. `Dedicated`, `Rededicated`, and `Presented to the United States` are distinct events and should not be collapsed into a generic date field.

Person memorials receive a short subject biography. Historical objects receive object context. This avoids inventing a human-subject field for objects such as the Cuban-American Friendship Urn.

Keep interpretive or disputed material below the overview unless its uncertainty can be represented accurately and compactly there.
