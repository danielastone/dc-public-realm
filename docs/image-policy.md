# Public image policy

Images on public object records must have an established reuse basis before publication.

## Selection order

1. Wikimedia Commons file with explicit license or public-domain status on the file page.
2. Government or cultural-institution asset with explicit public-domain or reusable-rights statement.
3. Project-owned photograph with an explicit license.

A publicly viewable image is not sufficient evidence of permission to republish it.

## Required metadata

Each published overview image records:

- `image_url`: the displayed image asset or stable redirect to it;
- `image_alt`: concise description of the depicted object;
- `image_credit`: creator or institutional credit required by the source;
- `image_rights`: public-domain status or exact license identifier;
- `image_source_url`: the source/file page documenting provenance and rights;
- `image_license_url`: license text when a reusable license applies.

For Creative Commons images, preserve creator attribution, license name, and a link to both the source file page and license. Do not replace creator attribution with a generic `Wikimedia Commons` credit.

## Current object-head images

- Artigas: National Park Service work, public domain; Commons file page used as the public rights/provenance record.
- San Martín: AgnosticPreachersKid, CC BY-SA 3.0, Wikimedia Commons.
- Cuban-American Friendship Urn: AgnosticPreachersKid, CC BY-SA 4.0, Wikimedia Commons.

Image rights establish permission to reproduce an image. They do not establish the truth of historical claims about the depicted object; those claims remain governed by the assertion/evidence model.
