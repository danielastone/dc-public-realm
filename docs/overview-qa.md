# Overview publication QA

A successful build should prove that all three current object records render an overview and preserve their distinguishing content:

- Artigas: public-domain NPS image, current location, 1950 dedication, subject context;
- San Martín: licensed Commons image, 1925 dedication, 1976 rededication, subject context;
- Cuban-American Friendship Urn: licensed Commons image, 1928 presentation, object context.

This is in addition to, not instead of, claim-status consistency checks on the detailed record.
