# Image policy test cases

Accept: a Commons photograph with named creator, explicit CC BY-SA license/version, source File page, license link, and suitable alt text.

Accept: an NPS photograph with an explicit U.S.-government public-domain basis and source record.

Reject: an image visible on a museum or agency webpage when no applicable reuse statement has been established.

Reject: a Commons URL with only `Wikimedia Commons` as credit when the file page identifies an individual creator.
