# Public image attribution display

The visible record-head caption should be concise but sufficient to preserve the rights chain:

`Creator / repository · license · Image record`

For public-domain government works, use the responsible institution as the credit and identify the public-domain basis. For Creative Commons works, link the displayed license name to the license text and `Image record` to the Commons file page.

Do not hide attribution only in metadata or a technical provenance panel. It belongs next to the reproduced image.
