# Object-head event semantics

Event labels describe documented events rather than a generic chronology field.

- `Dedicated` identifies a dedication ceremony.
- `Rededicated` identifies a later dedication after relocation or reinstallation when the source establishes that event.
- `Presented to the United States` identifies a diplomatic transfer or presentation and should not be rewritten as `Dedicated` without evidence of a dedication.

Preserving these labels prevents different stages of an object's public history from being collapsed into one date.
