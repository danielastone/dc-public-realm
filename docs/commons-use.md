# Wikimedia Commons usage

Wikimedia Commons is used as a rights-transparent image repository, not as authority for the project's historical assertions.

For each selected Commons image, retain the File page URL, named creator, explicit license, and license URL when applicable. The displayed asset may use Commons' stable file redirect. If a Commons file derives from a government source, record the underlying public-domain basis rather than implying that Commons created the image.

A Commons caption or category is not automatically imported into the historical record.
