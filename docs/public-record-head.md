# Public object record head

A public object page begins with enough information for a reader to understand what the object is before encountering claim-level provenance.

The record head contains a rights-cleared photograph, current location, presentation/dedication information appropriate to the object, and a short contextual introduction. Person memorials identify and briefly introduce the subject. Non-person objects use object context rather than forcing a subject biography.

The detailed assertion, evidence, source-history, and research-mission layers follow the overview. The overview improves orientation; it does not replace those layers.
