# Record-head visual hierarchy

The photograph and orientation facts form a single introductory unit below the object title. On wider screens the image and facts may sit side by side; on narrow screens they stack in reading order.

The visible hierarchy is:

1. object title;
2. documentary image and attribution;
3. location and event dates;
4. short subject biography or object context;
5. detailed assertion/status/source record.

The overview should not become a second navigation system or a dense metadata card. Its purpose is orientation before evidence inspection.
