# Image publication review checklist

Before an image is added to a public object head, confirm:

- the depicted object matches the catalog record;
- the source/file page is stable and recorded;
- the creator or responsible institution is identified;
- the license or public-domain basis is explicit;
- any license-required attribution is preserved visibly;
- Creative Commons license text is linked;
- alt text describes the image's useful visual content;
- image rights have not been treated as evidence for unrelated historical claims.

The automated gates check metadata completeness and URL structure. Human review remains necessary for identity, license interpretation, and image suitability.
