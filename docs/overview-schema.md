# Object overview publication schema

The record head is a reader-facing projection of sourced catalog information. It is not an independent factual layer.

Common fields: object ID, record type, current location and source, primary event label/date/source, and image metadata. Person memorials add subject name, dates, biography, and biography source. Historical objects use an object-context statement and source instead. Optional secondary events preserve distinct object-history events such as relocation or rededication.

The build must not publish an overview image unless credit, rights, source page, and alt text are present. Creative Commons assets also require a license URL. The image-rights record documents permission to reproduce the image; historical assertions remain governed by the assertion/evidence data.
